I created my first basic HTML webpage. I created an index.html file and used the essential HTML structure including <!DOCTYPE html>, html, head, and body elements. I set the page title to "My First Webpage" inside the head section using the title tag. Inside the body, I added a main heading using the h1 tag and added three subheadings using h2 and h3 tags to organize the content into different sections. I also used HTML comments <!-- --> to describe each section and maintained proper indentation to make the code clean and readable. Finally, I verified the webpage by opening it in a browser, where all headings were displayed correctly.
